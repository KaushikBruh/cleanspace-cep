CLEAN SPACES — COMMUNITY ENGAGEMENT PROJECT WEBSITE

HOW TO OPEN
1. Extract the ZIP file to a folder on your computer.
2. Open the folder and double-click index.html.
3. The website opens in your browser. No installation or server is required.

FILES
- index.html: page content
- styles.css: responsive design and layout
- script.js: mobile navigation interaction
- assets/: project photos extracted from the supplied PDF report

NOTES
- This is a static website and works without a backend.
- Internet is only needed for the optional Google Fonts; the site still works if they cannot load.
- Content and respondent counts are based on the supplied Community Engagement Project report.
- Before public hosting, confirm that all names, dates, mentor details, and photos are approved for publication.
